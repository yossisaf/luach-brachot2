# לוח ברכות – גרסה תואמת אנדרואיד 4.4 (API 19)

שם החבילה: `com.ys.foods` (שונה מהמקור `com.example.foods`, ולכן ההתקנה לא מתנגשת עם האפליקציה המקורית; ההגדרות/סימניות של המקור לא עוברות אוטומטית).

פרויקט Android Studio (Java, בלי תלויות חיצוניות, בלי הרשאות). minSdk 19.
הקוד נכתב מחדש ב-Views רגילים כי האפליקציה המקורית בנויה ב-Jetpack Compose שדורש API 21+
(שינוי minSdk ב-APK המקורי רק יגרום לקריסה).

## תוכן הברכות – לא שונה בשום צורה
- שלושת קבצי הנתונים (assets/blessings.txt, smell.txt, shehechiyanu.txt) זהים בייט-לבייט לקבצים שב-APK המקורי
  (res/9U.txt, wz.txt, vu.txt) – אומת ב-SHA-256.
- הפרסר (EntryParser) הוא העתק נאמן של הפרסר המקורי: אותם כללי חיתוך רווחים והרכבת שורות. אין שום עריכה, תיקון או עיצוב מחדש של הטקסט.
- שני הודעות הפתיחה (assets/notice_*.txt) הוצאו מילה במילה מ-resources.arsc של ה-APK.

## פונקציות (נשחזרו מקוד האפליקציה המקורית)
- דף הבית: חיפוש בכל הלוחות (קודם התאמה בשם, אחר כך בתוכן; "תוצאות: N"), חיפושים אחרונים (5), הצעת מאכל אקראי עם "הסר הצעה", ותפריט.
- שלושת הלוחות: ברכות הנהנין, ברכות הריח, שהחיינו ותולעים – כל אחד עם חיפוש. הודעת פתיחה עם "אל תציג שוב" (הנהנין ושהחיינו).
- סימניות (חיפוש בסימניות), היסטוריה (50 אחרונים, חיפוש, מחק מהיסטוריה, נקה הכל).
- מסך ערך: העתקה ללוח, סימנייה.
- סטטיסטיקות שימוש: סה"כ מאכלים, מאכלים שונים שבדקת, אחוז מהמאגר שנחקר, שלושת המאכלים המובילים (נפתחו לפחות פעמיים), איפוס סטטיסטיקות עם אישור.
- הגדרות: מצב לילה (יום/לילה/אוטומטי), עריכת נושא (6 צבעים), גודל טקסט (קטן/בינוני/גדול), הצגת מאכל אקראי, איפוס סטטיסטיקות.
- אודות, עם קישורים לאתר בית ההוראה ולדף האפליקציה בפורום מתמחים טופ (נפתחים בדפדפן; לאפליקציה עצמה אין הרשאת אינטרנט).
- שמות מפתחות ה-SharedPreferences זהים למקור (app_prefs, bookmarks, opened_history_v2, unique_opened_items, open_count|…, search_history, show_random, theme_mode, color_option, text_size_option).

קירובים (לא ניתן היה לשחזר 1:1 בלי הקוד המקורי של ה-UI): מכפילי גודל הטקסט, שהצעת המאכל נבחרת אקראית בכל הפעלה (ולא לפי יום), והפריסה הוויזואלית.

## מקשים פיזיים
- כל הרשימות: מעלה/מטה (ו-Page Up/Down) בתנועה, מרכז/Enter לפתיחה, ההדגשה ברורה בצבע.
- מקש SEARCH או הקלדת אות במקלדת פיזית: מעבר לחיפוש. BACK מנקה חיפוש ואז יוצא.
- מסך רשימה (לוח/סימניות/היסטוריה): מקש MENU (או לחיצה ארוכה) = פעולות על הפריט (סימנייה, מחק מהיסטוריה, נקה הכל).
- דף הבית: 1–7 קיצורי דרך (1-3 לוחות, 4 סימניות, 5 היסטוריה, 6 סטטיסטיקות, 7 הגדרות).
- מקש תפריט שמאלי (Soft Left) פועל כמו MENU.
- מסך ערך: מעלה/מטה/Page/רווח לגלילה; ימינה/שמאלה ערך קודם/הבא; * סימנייה; # העתקה; MENU פעולות.

## פונט
הפרויקט כולל את Liberation Sans (Regular + Bold, רישיון SIL OFL 1.1; הרישיון ב-assets/fonts). הפונט כולל את כל טווח העברית ואת כל התווים שמופיעים בנתונים (גרש, גרשיים, מקף עברי), ולכן הטקסט נראה אותו דבר בכל מכשיר, גם אם ב-ROM של 4.4 אין פונט עברי טוב. הפונט מוחל על כל המסכים והדיאלוגים.

## אייקון
האייקון הוא האייקון המקורי של האפליקציה (חולץ מה-APK בכל חמש הצפיפויות, מרובע ועגול) – res/mipmap-*.

## בנייה
(מומלץ Build APK מסוג Debug – הוא חתום אוטומטית וניתן להתקנה ישירה.)

Android Studio (Hedgehog+, JDK 17): Open, Sync, Build > Build APK(s).
הקוד לא קומפל בסביבה שבה נוצר (אין Android SDK שם): נבדק תחביר של כל הקבצים והרצת הפרסר על הנתונים האמיתיים (test/ParserTest.java).
